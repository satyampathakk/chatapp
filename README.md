#  Anonymous & Secure Chat App over Tor

> Private and secure communication using FastAPI, Tor Hidden Services, and PGP Encryption.

---

##  About

This project allows users to securely and anonymously chat by connecting through **Tor** and encrypting their messages with **PGP**.  
No accounts, no tracking — only people you **share your .onion address with** can contact you.

The app uses a lightweight **FastAPI server** backend, and can optionally connect through an Android app (.apk).

---

##  Features

- **Tor Network Integration**: Full anonymity by running a hidden service.
- **PGP Encryption**: End-to-end encrypted messages.
- **Private Connections**: Only users who know your `.onion` address can connect.
- **FastAPI Backend**: High-performance and easy-to-deploy server.
- **MIT Licensed**: Free for anyone to use, modify, and contribute.
- **Optional Android APK**: Lightweight app to connect easily.

---

## 🚀 How It Works

1. **Setup FastAPI Server**: Run the backend on your machine.
2. **Run Tor Service**: Configure Tor to expose your server as a hidden service (.onion).
3. **Add .onion Address**: Use the app to input the `.onion` address of the person you want to chat with.
4. **Encrypt Messages**: All communications are encrypted using PGP keys.
5. **Secure Chat**: Enjoy fully private conversations over the Tor network.

## 🛠️ Setup Instructions

### Requirements

- Python 3.10+
- FastAPI
- Uvicorn
- Tor (with permission to create hidden services)
### Installation

1. **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    cd your-repo-name
    ```

2. **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3. **Start your Tor service** and configure a hidden service that points to your FastAPI port (e.g., 8000).

4. **Run the FastAPI server**:
    ```bash
    uvicorn main:app --host 127.0.0.1 --port 8000
    ```

5. **Use your `.onion` address** generated by Tor in the app to connect securely.
